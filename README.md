
# Student Management System

A full-stack Student Management System developed
using React, Java Spring Boot and PostgreSQL.

## Technology Stack

- Frontend: React + Vite
- Backend: Java + Spring Boot
- Database: PostgreSQL
- API: REST API

## Main Features

- Student Registration
- Student Records Management
- Search and Update Students
- Course Management
- Attendance Management
- Result and Grade Management
- Student Reports

## Academic Purpose

This project demonstrates Java concepts from:

- Unit 2: Inheritance and Interface
- Unit 3: Exception Handling and Multithreading
- Unit 4: Generic Programming
